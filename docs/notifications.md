# Система уведомлений OrrClockLinux

## 1. Типы уведомлений

### А. Звуковые уведомления
1. **15-минутное предупреждение** - срабатывает, когда до намаза остается 15 минут или меньше
   - Файл: `audio/notice/Ahmet/Ahmet-15dakikakaldi.mp3`
   - Активируется автоматически при приближении времени намаза

2. **30-минутное предупреждение** 
   - Файл: `audio/notice/Ahmet/Ahmet-30dakikakaldi.mp3`
   - Активируется ровно за 30 минут до намаза

3. **45-минутное предупреждение**
   - Файл: `audio/notice/Ahmet/Ahmet-45dakikakaldi.mp3`
   - Активируется ровно за 45 минут до намаза

4. **60-минутное предупреждение**
   - Файл: `audio/notice/Ahmet/Ahmet-60dakikakaldi.mp3`
   - Активируется ровно за 60 минут до намаза

5. **Уведомление о начале намаза**
   - Состоит из двух частей:
     1. Голосовое уведомление: `audio/notice/Ahmet/Ahmet-VaxtGirdi.mp3`
     2. Азан: `audio/adhan/Adhan01.mp3`

### Б. Визуальные уведомления
1. **Мигание времени следующего намаза**
   - Активируется за 15 минут до намаза
   - Частота мигания: каждые 500 мс
   - Прозрачность переключается между 1.0 (полностью видимый) и 0.0 (полностью прозрачный)

2. **Цветовые индикаторы**
   - Желтое мигание за 30 минут до намаза
   - Оранжевое мигание за 45 минут до намаза
   - Красное мигание за 60 минут до намаза

## 2. Техническая реализация

### А. Класс NextPrayerTimeBox
Основная логика уведомлений реализована в классе `NextPrayerTimeBox` (файл `ui/next_prayer_time_box.py`).

#### Ключевые методы:
1. `_play_notification_sound(notification_type)` - воспроизводит звуковые уведомления
2. `_start_time_blink()` - запускает анимацию мигания
3. `_update_time_blink(dt)` - обновляет анимацию мигания
4. `_stop_time_blink()` - останавливает анимацию мигания
5. `_play_sound_file(sound_file, is_adhan)` - воспроизводит звуковой файл

#### Атрибуты для анимации:
```python
# Для анимации мигания времени следующего намаза
self._is_time_blinking = False
self._blink_event = None
self._blink_opacity = 1.0

# Для анимации предупреждения за 30 минут
self._is_30min_warning = False
self._30min_blink_event = None
self._30min_blink_opacity = 1.0

# Для анимации предупреждения за 45 минут
self._is_45min_warning = False
self._45min_blink_event = None
self._45min_blink_opacity = 1.0

# Для анимации предупреждения за 60 минут
self._is_60min_warning = False
self._60min_blink_event = None
self._60min_blink_opacity = 1.0
```

### Б. Воспроизведение звука
- Используется библиотека `mpv` для воспроизведения звука
- Звуки воспроизводятся в отдельном потоке, чтобы не блокировать интерфейс
- Реализована защита от частых срабатываний (не чаще 1 раза в 30 секунд)

### В. Проверка времени
- Проверка оставшегося времени до намаза выполняется в методе `update_time()`
- Используются вспомогательные методы:
  - `_is_within_15_minutes_before_prayer()`
  - `_is_exactly_30_minutes_before_prayer()`
  - `_is_exactly_45_minutes_before_prayer()`
  - `_is_exactly_60_minutes_before_prayer()`

## 3. Особенности реализации

1. **Потокобезопасность**:
   - Для управления воспроизведением звука используется блокировка `_sound_lock`
   - Воспроизведение звука вынесено в отдельный поток

2. **Обработка ошибок**:
   - Проверка существования звуковых файлов
   - Логирование ошибок воспроизведения
   - Защита от падений при ошибках

3. **Производительность**:
   - Анимации используют аппаратное ускорение через Kivy
   - Минимизирована нагрузка на UI-поток

4. **Настраиваемость**:
   - Цвета анимаций берутся из текущей темы
   - Поддерживаются разные звуковые файлы для разных типов уведомлений

## 4. Логика работы

1. При запуске приложения создается экземпляр `NextPrayerTimeBox`
2. Каждую минуту вызывается метод `update_time()`
3. Проверяется оставшееся время до следующего намаза
4. В зависимости от оставшегося времени активируются соответствующие уведомления
5. Звуковые уведомления воспроизводятся с помощью `_play_notification_sound()`
6. Визуальные уведомления активируются через соответствующие методы `_start_*_warning()`
