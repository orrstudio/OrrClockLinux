# План рефакторинга системы уведомлений о времени намаза

## Текущая архитектура

### Методы проверки времени:
1. `_is_within_15_minutes_before_prayer` - проверка 15 минут
2. `_is_exactly_30_minutes_before_prayer` - проверка 30 минут
3. `_is_exactly_45_minutes_before_prayer` - проверка 45 минут
4. `_is_exactly_60_minutes_before_prayer` - проверка 60 минут

### Методы анимаций:
1. `_start_time_blink` / `_stop_time_blink` - для 15 минут
2. `_start_30min_warning` / `_stop_30min_warning`
3. `_start_45min_warning` / `_stop_45min_warning`
4. `_start_60min_warning` / `_stop_60min_warning`

### Звуковые уведомления:
- `_play_notification_sound` с типами: '15min', '30min', '45min', '60min', 'prayer_change'

## План изменений

### 1. Создание единого метода проверки времени

```python
def _check_prayer_time(self, current_time, next_prayer_time_str):
    """
    Проверяет оставшееся время до намаза и возвращает кортеж (найдено_совпадение, минут_до_намаза)
    """
    minutes = self._get_minutes_until_prayer(current_time, next_prayer_time_str)
    
    # Проверяем все временные интервалы
    if minutes == 15:
        return True, 15
    elif minutes == 30:
        return True, 30
    elif minutes == 45:
        return True, 45
    elif minutes == 60:
        return True, 60
    
    return False, minutes
```

### 2. Создание единого метода уведомлений

```python
def _handle_prayer_notification(self, minutes_left, next_prayer_time_str):
    """
    Обрабатывает уведомление о времени до намаза
    
    Args:
        minutes_left (int): Количество минут до намаза (15, 30, 45, 60)
        next_prayer_time_str (str): Время следующего намаза в формате 'ЧЧ:ММ'
    """
    # Останавливаем все текущие анимации
    self._stop_all_animations()
    
    # Запускаем соответствующую анимацию
    if minutes_left == 15:
        self._start_time_blink()  # До намаза
        self._play_notification_sound('15min')
    elif minutes_left == 30:
        self._start_30min_warning()
        self._play_notification_sound('30min')
        Clock.schedule_once(lambda dt: self._stop_30min_warning(), 60)  # Через 1 минуту
    elif minutes_left == 45:
        self._start_45min_warning()
        self._play_notification_sound('45min')
        Clock.schedule_once(lambda dt: self._stop_45min_warning(), 60)  # Через 1 минуту
    elif minutes_left == 60:
        self._start_60min_warning()
        self._play_notification_sound('60min')
        Clock.schedule_once(lambda dt: self._stop_60min_warning(), 60)  # Через 1 минуту
```

```python
def _stop_all_animations(self):
    """Останавливает все активные анимации"""
    if self._is_time_blinking:
        self._stop_time_blink()
    if self._is_30min_warning:
        self._stop_30min_warning()
    if self._is_45min_warning:
        self._stop_45min_warning()
    if self._is_60min_warning:
        self._stop_60min_warning()
```
