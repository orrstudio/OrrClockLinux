# Руководство по стилю кода PEP 8

## Основные принципы

### 1. Отступы
- Используйте 4 пробела на каждый уровень отступа
- Не смешивайте табуляцию и пробелы

### 2. Длина строки
- Максимальная длина строки — 79 символов
- Для комментариев — не более 72 символов
- Используйте обратный слэш `\` или скобки для переноса длинных строк

### 3. Пустые строки
- 2 пустые строки перед объявлением класса
- 1 пустая строка между методами класса
- 1 пустая строка между логическими блоками кода

### 4. Импорты
Группируйте импорты в следующем порядке:
1. Стандартная библиотека
2. Сторонние библиотеки
3. Локальные модули

Каждая группа отделяется пустой строкой.

### 5. Пробелы в выражениях
- `a = 1` (пробелы вокруг операторов)
- `func(1, 2, key=value)` (без пробелов вокруг скобок)
- `spam(ham[1], {eggs: 2})` (без пробелов вокруг скобок)

### 6. Именование
- `переменные_и_функции` — нижний регистр с подчёркиваниями
- `Классы` — CamelCase с заглавной буквы
- `КОНСТАНТЫ` — верхний регистр с подчёркиваниями
- `_внутренние` — с одним подчёркиванием в начале (для внутреннего использования)
- `__приватные` — с двумя подчёркиваниями (для приватных атрибутов)

### 7. Комментарии
- Полные предложения с заглавной буквы и точкой
- Обновляйте комментарии при изменении кода
- Избегайте комментариев, которые дублируют код

### 8. Строки документации (docstrings)
- Используйте тройные кавычки `"""`
- Первая строка — краткое описание
- Вторая строка — пустая
- Далее — подробное описание

## Пример кода, соответствующего PEP 8

```python
import os
from datetime import datetime

CONSTANT = 42

def example_function(param1, param2):
    """
    Пример функции с документацией.
    
    Args:
        param1: Первый параметр
        param2: Второй параметр
        
    Returns:
        int: Результат вычисления
    """
    if param1 > 0:
        result = param1 + param2
    else:
        result = param1 - param2
    return result


class ExampleClass:
    """Пример класса с документацией."""

    def __init__(self, value):
        self.value = value

    def get_value(self):
        """Возвращает значение."""
        return self.value
```

## Автоматические инструменты
Для проверки и автоматического форматирования кода в соответствии с PEP 8 используйте:

- `autopep8` — автоматическое форматирование кода
- `flake8` — проверка стиля кода
- `black` — "бескомпромиссный" форматтер кода
- `pylint` — статический анализатор кода

## Важные замечания
1. Соблюдение PEP 8 делает код более читаемым
2. Единообразие важнее, чем следование каждому правилу
3. В некоторых случаях можно отступать от правил, если это улучшает читаемость
4. Всегда следуйте стилю существующего кода в проекте
