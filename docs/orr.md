ОКНО НАСТРОЙКА: 
Рефакторинг - вынести каждый блок в отдельный файл. 

ui/settings_blocks/
├── colors.py          # Цвета часов
├── azan-spinner.py          # Настройки азана Spinner
├── azan-dropdown.py          # Настройки азана DropDown
├── azan-popup.py          # Настройки азана Popup
├── notifications.py         # Блок аудио уведомлений
├── admin.py         # Админ панель
ui/settings_blocks/base/         # Базовые классы (ResponsiveLabel, SettingsCard и т.д.)
├── xxx.py           # Класс ххх

Все делаем по порядку по очереди: к примеру: сначало создаем colors.py в отдельном файле (удаляем при этом его из фала сеттингс окно) с точностью до милиметра как в оригинале. тестим если работает идем дальше создавать и тестить следующий блок. в самом конце создаем базовые классы. можно начать и с базовых классов, но после каждого переноса с удалением нужно проверять работоспособность.
