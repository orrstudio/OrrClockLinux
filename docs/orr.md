ОКНО НАСТРОЙКА: Рефакторинг

Основное окно настроек находится в файле settings_window.py
Нужно сделать Рефакторинг этого окна - вынести каждый блок в отдельный файл. 

Cтруктуру директорий:

ui/settings_blocks/
├── colors.py
├── azan-spinner.py
├── azan-dropdown.py
├── azan-popup.py
├── notifications.py
├── admin.py
└── base/
    ├── __init__.py
    ├── responsive_label.py
    ├── settings_card.py
    └── settings_section.py

Последовательность рефакторинга:

Сначала вынесем базовые классы в папку base:
ResponsiveLabel
SettingsCard
SettingsSection
CustomButton

Затем последовательно вынесем блоки:
colors.py - настройки цветов
azan-spinner.py - спиннер выбора азана
azan-dropdown.py - выпадающий список азана
azan-popup.py - всплывающее окно азана
notifications.py - настройки уведомлений
admin.py - админ-панель

После каждого переноса:
Удаляем код из оригинального файла
Импортируем классы из новых модулей
Тестируем работоспособность

В конце:
Обновим импорты в основном файле
Проверим все зависимости
Протестируем полную функциональность
